Auto Organizer

Choose your completed-download folder and existing Jellyfin libraries. These settings use folders visible inside the Jellyfin container on your Synology NAS.

Allows the “Organize incoming downloads” task to process downloads. It runs every minute by default. Change the interval under Dashboard → Scheduled Tasks → Auto Organizer.
Records proposed destinations in Dashboard → Logs as “AutoOrganizer Preview”, without creating library files or removing downloads. Leave this enabled until the results look correct.

Incoming downloads

Choose the folder your torrent client uses for finished downloads. Browse shows folders on the Jellyfin server, not your computer. On Synology, open Container Manager → your Jellyfin container → Volume settings. Find the completed-downloads mapping and use its container-side path, for example /downloads/completed. File Station shows the host-side folder, such as /volume1/downloads/completed; that path usually differs. If the folder is missing from Browse, add its bind mount and grant Jellyfin read access in DSM. Move mode also needs permission to delete source files.

Library destinations

These dropdowns list folders already configured in Dashboard → Libraries. Choose one destination per media type. If a library has several folders, each appears separately. Selecting a folder here does not change Jellyfin's library settings.

Choosing a Shows library fills its actual folder here, for example /media/TV. Episodes go directly inside it: /media/TV/Series Name/Season 01. Leave blank to use Shows inside the shared root. If you browse to a custom folder, add it to a Shows library under Dashboard → Libraries. Grant the Jellyfin container user write access through DSM shared-folder permissions.
Choosing a Movies library fills its actual folder here, for example /media/Films. Movies go directly inside it: /media/Films/Movie Name (2024). Leave blank to use Movies inside the shared root. Add custom folders to a Movies library under Dashboard → Libraries. Jellyfin needs write access to this folder.
Use a common parent such as /media to create /media/Shows and /media/Movies. Suggestions include parents of existing library folders. Each destination above overrides its part of this root. If both destinations are filled, this field can be blank. Incoming and library folders must be separate, with neither inside the other; Shows and Movies destinations must also be separate. Your existing shared-root setting continues to work after upgrading.

Browse server folders

This is the filesystem visible inside your Jellyfin container. Only mounted folders are accessible; it does not expose the entire Synology filesystem. Select an existing folder here. This browser does not upload files or create folders.

Import behavior

Copy keeps the torrent's original files for seeding and uses extra disk space. Move removes successfully imported videos and matching subtitles/audio after checks complete; choose it only when your downloader no longer needs the originals. Existing destination files are never overwritten.
Default 300 seconds (5 minutes). File size and modification time must stay unchanged across polls for this duration. A restart starts the observation period again, and manual scans also honor the delay. Paused torrents can appear stable, so point incoming at completed downloads or use a completion marker.
Leave blank unless your downloader creates a marker when it finishes. Enter just a filename such as .completed, not a path. Configure the downloader's completion hook to create this file inside each top-level release folder. With a marker configured, folders without it and loose files directly in incoming are skipped.
Creates “Series Name (2024)” instead of “Series Name” when the release name includes a year, helping distinguish remakes. Existing imported folders are not renamed.
